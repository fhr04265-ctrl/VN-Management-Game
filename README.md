# 訪問看護ステーション経営シミュレーター MVP

訪問看護の新任管理者・管理者候補が、売上、利益、現預金、稼働率、チーム継続リスク、ケア品質、請求品質のつながりを体験するための研修用Webアプリです。

## 使い方

`index.html` をブラウザで開くと、そのままプレイできます。サーバー、データベース、ログイン、外部APIは使っていません。

GitHub Pagesを有効にすると、スマートフォンからもブラウザでプレイできます。

## 主な機能

- 12か月研修モードと60か月経営モード
- 既存引き継ぎ、新規開設、高稼働疲弊ステーションのシナリオ
- 売上と現金入金の2か月ズレ
- 採用、利用者獲得、利用者終了、疲弊、品質、地域信頼の連動
- 現預金0円未満、看護師3名未満のゲームオーバー条件
- 採用、加算、退職申告などのイベントをグラフに表示
- CSV出力

## セキュリティ上の位置づけ

このMVPは完全な静的アプリです。

- 外部通信なし
- データベースなし
- APIキーなし
- 環境変数なし
- 個人情報入力なし
- CSVはブラウザ内で生成

将来的にSupabaseなどのDBを使う場合は、RLS、Policy、API経由の認証認可、secret keyの非公開、入力バリデーション、レートリミット、ログへの個人情報出力禁止、secret scan / dependency scanを必須にしてください。
